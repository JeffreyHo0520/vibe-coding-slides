# 職場 Vibe Coding 工作術 HTML 互動簡報

本簡報採用 Reveal.js 框架開發，具備現代化科技風格與即時互動功能。

* **💻 簡報網址**：[https://jeffreyho0520.github.io/vibe-coding-slides/](https://jeffreyho0520.github.io/vibe-coding-slides/)

## 🛠️ 技術規格
* **簡報框架**：Reveal.js 5.1.0
* **即時互動**：Firebase Firestore (字體雲、單選投票)
* **視覺技術**：Clip-path before/after 滑桿對比
* **資產處理**：AI 生成背景底圖、去背霓虹圖示
